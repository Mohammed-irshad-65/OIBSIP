# Mohammed Irshad - Front-End Developer Portfolio

A responsive, high-performance personal portfolio website built with clean HTML5, CSS3, and modern Vanilla JavaScript. Features a dark futuristic aesthetic with glassmorphism UI elements, glowing visual accents, and an interactive background canvas.

---

## 🚀 Live Demo

[View Live Portfolio](https://your-domain-or-github-pages-link.com)

---

## ✨ Features

- **Futuristic & Dark Mode UI:** Built using glassmorphism designs, glowing borders, and neon color gradients.
- **Interactive Background:** HTML5 Canvas particle network animation that dynamically updates on screen resize.
- **Dynamic Typewriter Effect:** Custom Vanilla JS typewriter script cycling through key professional roles.
- **Responsive Navigation:** Sticky header with active section tracking on scroll and a mobile-friendly slide menu.
- **Project Showcase Grid:** Interactive cards displaying key projects, technology badges, and live demo/code links.
- **Functional Contact Form:** Front-end form validation with instant user visual feedback.
- **Pure Native Web Tech:** Zero dependencies on external JavaScript framework binaries or CSS preprocessors.

---

## 🛠 Tech Stack

- **Markup:** HTML5 (Semantic Structure)
- **Styling:** Modern CSS3 (Flexbox, CSS Grid, Custom Properties, Keyframe Animations, Glassmorphism)
- **Scripting:** Vanilla JavaScript (ES6+, DOM Manipulation, HTML5 Canvas API)
- **Icons & Fonts:** FontAwesome 6, Google Fonts (*Inter* & *Poppins*)
